# 성과지표가 있을 때

C에서 지표명·정의·목적, 세부평가내용 원문과 순서, 평가방법, 배점·가중치, 평가 기준 키워드, 전년도 지적사항, 지정 과제를 원장에 옮긴다.

## 목차와 지면

- 기본은 세부평가내용 1개 = 대제목 1개이고 원문 순서를 따른다.
- 지면이 짧고 D가 허용하면 밀접한 인접 항목을 묶되 `평가 항목 → 보고서 위치 → 근거 ID` 대응을 남긴다.
- 제목에는 지표 핵심어를 그대로 넣어 평가자가 찾게 한다.
- 배점이 있으면 지면도 비례시킨다. 배점이 없으면 근거의 양과 질로 정한다.
- 노력과 성과를 함께 묻는 항목은 체계·과정과 정량 결과를 모두 둔다.
- 근거가 없는 항목은 꾸미지 말고 자료 부족으로 보고한다.

| 평가 키워드 | 보여줄 근거 |
|---|---|
| 적정성·정합성 | 정책·기관 전략과의 연결 |
| 체계성 | 단계·역할·절차와 운영 실적 |
| 적극성·노력 | 추진 경과, 주도·협업 구분 |
| 차별성 | 기존→개선, 최초·유일의 원문 근거 |
| 성과·효과 | 전후·목표 대비, KPI |
| 확산·지속 | 제도화, 타 부서·기관 확산 |
| 환류 | 문제→개선→재점검, 지적 대응 |

지적사항은 관련성과 올해 조치·결과 근거를 확인한다. 원문을 모두 검토하되 억지로 전부 본문에 넣지 않는다.
