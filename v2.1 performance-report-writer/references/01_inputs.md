# 01. 입력 판별과 작업 모드

## 1. 입력의 네 가지 역할

| 역할 | 필수 여부 | 이 입력이 정하는 것 | 판별 단서 |
|---|---|---|---|
| **작성 자료** | 필수 | 쓸 **내용**(사실·수치·사례·그림) | 우리 조직의 실적: 계획안, 결과보고, 증빙, 회의자료, 보도자료, 내부 메모, 과제 목록 엑셀. 안에 든 사진·그래프·화면도 보고서 재료다 |
| **양식(템플릿)** | 선택 | 분석한 내용을 **어떻게 보여줄지**: 표현 구조·말투·지면 | 완성된 보고서 지면. 짧음(1~6쪽), 박스·도식·표 중심, 다른 조직이나 다른 연도 실적, '예시' 표기 |
| **성과지표** | 선택 | **무엇을** 말할지: 방향·목차 뼈대·강조점 | 지표명, 지표 정의, 세부평가내용, 평가방법, 가중치, 평가 기준, 전년도 지적사항 |
| **작성 가이드라인** | 선택 | 지켜야 할 **제약** | 작성요령·유의사항. 쪽수 상한, 글자 크기, 필수 항목, 금지 표현 등 규정 문장 |

사용자 메시지의 지시(쪽수, 강조할 사업, 부서명, 제출처 등)는 모든 첨부보다 우선한다.

## 2. 판별 절차

1. 모든 첨부의 앞 2~3쪽, 목차, 제목, 머리말·바닥글을 읽는다.
2. 양식 후보는 반드시 **이미지로 보고** 판단한다. 글자만으로는 지면 구조를 알 수 없다.
3. 한 파일에 역할이 섞여 있으면 쪽 범위별로 나눈다(예: 편람 1~3쪽은 성과지표, 4~6쪽은 가이드라인).
4. 판별 결과를 **판별표**로 남긴다: `파일 | 역할 | 근거 한 줄`.
5. 판단이 갈리고 결과가 크게 달라지는 파일만 짧게 묻는다. 물을 수 없으면 가장 그럴듯한 판단으로 진행하고 그렇게 했다고 밝힌다.

헷갈리는 경우:
- **다른 조직의 완성된 보고서** → 양식이다. 내용은 절대 가져오지 않는다.
- **우리 조직의 작년 보고서** → 양식이면서 작성 자료(전년 실적·비교 기준)이기도 하다. 두 역할을 모두 쓴다. 전년 수치는 비교 후보(`02_analysis.md` 8절)로 모은다.
- **평가 결과 통보서·지적사항** → 성과지표 쪽에 넣는다. 전부 분석하되, 해당 지표·핵심 메시지와 직접 관련되고 올해 조치·결과 근거가 있는 것만 본문에 반영한다. 나머지는 미반영 사유를 기록한다.
- **과제 목록 엑셀** → 작성 자료다. 엑셀 안의 분류 체계는 그대로 따른다.

## 3. 작업 모드

| 모드 | 첨부 | 방향(무엇을) | 구조·말투(어떻게) | 지면 |
|---|---|---|---|---|
| A | 자료만 | 자료 분석으로 방향·스토리라인 도출 (`03_direction.md` 2절) | 기본 문체 (`05_style.md` 3절) | 기본 양식 (`09_default_template.md`) |
| B | 자료 + 양식 | 자료 분석으로 방향·스토리라인 도출 | 완성한 스토리라인을 양식의 구조·말투에 맞춤 | 양식 지면 |
| C | 자료 + 성과지표 | 지표가 방향·필수 목차, 자료 분석이 스토리라인 (`03_direction.md` 1절) | 기본 문체 | 기본 양식 |
| D | 자료 + 양식 + 성과지표 | 지표가 방향·필수 목차, 자료 분석이 스토리라인 | 양식의 구조·말투에 맞춤 | 양식 지면 |

**내용 우선 원칙.** 작성 자료가 모든 사실의 근거다. 성과지표는 '무엇을 평가받아야 하는지', 양식은 분석한 내용을 '어떻게 보여줄지'를 정한다. 사실 카드 → 방향 → 스토리라인을 먼저 완성하고 마지막에 양식 칸에 대응시킨다. 양식의 빈칸을 채우려고 C등급 내용이나 근거 없는 문장을 넣지 않는다.

성과지표와 양식이 부딪히면 이렇게 한다.
- 양식의 칸이 일반 칸(추진배경·추진내용·추진성과 등)이면 칸 구조는 양식대로 두고, 그 안을 지표 항목으로 채운다.
- 양식의 제목이 주제어(다른 조직의 사업명 등)면 지표 항목의 핵심어로 바꾼다.
- 양식의 칸 순서 때문에 문제→조치→성과의 흐름이 끊기면 필수 칸은 유지하되, 각 칸 안의 근거 순서와 강조를 조정해 스토리라인을 살린다.

**우선순위:** 내용·방향은 사용자 지시 > 성과지표 > 작성 자료 분석. 형식은 사용자 지시 > 가이드라인 > 양식 > 기본 양식.

**기본 양식.** 양식이 첨부되지 않으면 `09_default_template.md`의 지면(왼쪽 라벨 칸 + 여러 열 표, 회색 계열)을 쓴다. 사용자가 "양식 없이 간단히", "서술형으로"처럼 다른 지면을 원하면 그 지시가 우선한다.

## 4. 쪽수 결정

사용자 지정 > 가이드라인 상한 > 양식 샘플 쪽수 > 자료 분량에 맞춘 판단(기본 2쪽).
쪽수가 정해지면 끝까지 지킨다. 넘치면 약한 내용을 빼고, 모자라면 자료에서 강한 근거를 더 찾는다. 더 넣을 근거가 없으면 약한 내용을 늘리지 말고 여백을 허용해 자료 부족을 알린다. 글자 크기를 조절해 맞추지 않는다.
