# 데모: 가상 기관의 안전관리 실적보고서

> 기관명·사업·수치·그림은 모두 **가상**입니다. 스킬이 자료를 어떻게 읽고 엮는지 보여주기 위한 예시입니다.

## 넣은 것 (inputs/)
| 파일 | 역할 |

| `01_예측정비_결과보고.md` | 작성 자료 — 결과보고 |
| `02_예측정비_추진계획.md` | 작성 자료 — 계획·중간 점검 (결과와 수치가 다름) |

| `04_현장자료_그림모음.docx` | 작성 자료 — 그래프·앱 화면 등 그림 4개와 작은 아이콘 |
| `성과지표_예시.md` | 성과지표 — 세부평가내용 3개, 전년도 지적사항 |

요청: "첨부 자료로 성과지표에 맞춰 실적보고서 써줘" → **모드 C**(자료 + 성과지표), 양식 없음 → **기본 양식**, 쪽수 지정 없음 → 2쪽

## 눈여겨볼 판단
1. **지표가 목차를 정함**: 세부평가내용 ①체계 ②위험요인 발굴 ③안전문화 → 대제목 1·2·3, 같은 순서
2. **기본 양식**: 양식이 없어 평가내용 → 핵심성과 → 대제목 → 중제목 → 라벨 칸 표 구성으로 작성
3. **비교 값 선별**: 돌발 고장 '25년 14건 → '26년 3건(79%↓), 위험요인 발굴 2.4배 등 섹션별 1~3개만. 기준값이 작은 '기록 누락 6→0건'은 %가 아닌 실수치로
4. **그림 선별**: 원자료 그림 4개 중 3개만 관련 칸 안에 작게. 글자 빽빽한 계획 슬라이드는 제외, 아이콘은 자동으로 걸러짐
5. **수치 충돌 처리**: 계획서의 중간 점검(4건, 6월)보다 결과보고(3건, 9월)를 채택
6. **지적사항 대응**: 전년 지적 '관리자 점검 의존' → 2번 섹션 첫 행에서 지적 → 개선 → 결과(협력사 신고 41%)
7. **지어내지 않음**: 자료에 없는 정책 근거·향후계획은 쓰지 않고, 드론 점검('??' 검토 중)은 제외
