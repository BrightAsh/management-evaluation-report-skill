# 평가지표: 안전관리 체계 고도화 (가상 예시)

| 구분 | 내용 |
|---|---|
| 배점 | 3점 (정성, 9등급) |
| 지표 정의 | 기관의 안전관리 체계를 고도화하고, 위험요인을 선제적으로 발굴·개선하며, 안전문화를 확산하기 위한 노력과 성과를 평가 |

**세부평가내용**
1. 안전관리 체계 구축·운영의 적정성
2. 위험요인 발굴·개선 노력과 성과
3. 안전문화 확산 노력과 성과

**평가 착안사항:** 체계성, 현장 참여, 정량 성과(전년 대비), 확산

**전년도 지적사항:** 위험요인 발굴이 관리자 점검에 의존하고 있어 현장 참여 확대 필요

※ 예시용 가상 지표임
