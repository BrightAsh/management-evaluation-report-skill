## v2.2.0 · performance-report-writer

**[바로 다운로드 (.zip)](https://raw.githubusercontent.com/BrightAsh/management-evaluation-report-skill/main/v2.2.0%20performance-report-writer/dist/performance-report-writer-v2-2-0.zip)** · [상세 문서](v2.2.0%20performance-report-writer/)

- 기준 양식에 맞춰 첫 쪽을 `제목 → 평가내용 → 핵심성과 → 대제목` 순서로 수정했습니다.
- 최상단 BEST PRACTICE 상자를 제거하고 대표 사례는 중제목의 `B.P` 태그로 표시했습니다.
- 머리말·바닥글·옆 탭과 지면별 블록 대응을 보강했습니다.
- 원자료 그림 사용과 `[이미지 삽입]` 표시 기준을 확대했습니다.
