자료를 이렇게 엮습니다

같은 사실도 엮는 방식에 따라 '열심히 했다'로도, '확실히 바꿨다'로도 읽힙니다. 스킬은 제목부터 주장으로 세웁니다.

흔한 보고서
안전관리 추진 실적
  • 점검 앱 도입
  • 3년치 일지 입력
  • 경보 기준 확정
  • 돌발 고장 감소
이 스킬이 쓰는 방식
예측 정비 체계 구축으로 돌발 고장 79% 감소
  • 문제: 종이 일지라 추세를 못 봄 ➡ 돌발 고장 14건
  • 추진: 앱 도입 → 3년치 입력 → 경보 운영
  • 성과: 14건 → 3건, 목표(7건) 초과 달성

가상 기관 예시입니다. 문제에서 꺼낸 숫자(14건)가 성과에서 같은 단위로 돌아오도록 짝을 맞춥니다.

  1. 첨부 판별자료·양식·지표·가이드라인 역할 구분
  2. 자료 분석모든 사실을 출처와 함께 카드로, 사업별 등급
  3. 방향 설정핵심 메시지 1문장과 축 2~4개
  4. 흐름·구조 설계주장형 제목, 제목만 읽어도 이해되는 순서
  5. 문체양식의 말투 그대로, 없으면 개조식
  6. 지면흐름도·비교·숫자 타일·표·성과 박스
  7. 결과물PDF + Word, 정한 쪽수에 정확히
  8. 점검모든 수치를 원문과 대조

쓰는 AI에 맞게 설치하기

  1. performance-report-writer.zip을 받습니다. 압축을 풀지 말고 그대로 씁니다.
  2. Claude 설정에서 코드 실행을 켜고, 스킬 메뉴에서 zip을 업로드합니다.
  3. 자료를 첨부하고 요청하면 스킬이 자동으로 켜집니다. "사용법 알려줘"라고 하면 안내가 나옵니다.
  1. 저장소를 개인 스킬 폴더에 받습니다. 프로젝트 전용이면 .claude/skills/ 아래에 받습니다. git clone https://github.com/BrightAsh/performance-report-writer ~/.claude/skills/performance-report-writer
  2. Word 출력용으로 npm install, PDF 출력용으로 pip install playwright를 한 번 실행합니다.

이 스킬은 공개 표준인 Agent Skills(SKILL.md) 형식입니다. OpenAI Codex, Gemini CLI, Cursor, GitHub Copilot 같은 도구의 스킬 폴더에 넣으면 됩니다. 폴더 위치는 도구마다 다르니 각 도구의 문서를 확인하세요.
