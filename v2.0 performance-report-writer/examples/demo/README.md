# 데모: 가상 기관의 안전관리 실적보고서

> 기관명·사업·수치는 모두 **가상**입니다. 스킬이 자료를 어떻게 읽고 엮는지 보여주기 위한 예시입니다.

## 넣은 것 (inputs/)
| 파일 | 역할 |
|---|---|
| `01_예측정비_결과보고.md` | 작성 자료 — 결과보고 |
| `02_예측정비_추진계획.md` | 작성 자료 — 계획·중간 점검 (결과와 수치가 다름) |
| `03_위험신고_안전문화_실적.md` | 작성 자료 — 실적 |
| `성과지표_예시.md` | 성과지표 — 세부평가내용 3개, 전년도 지적사항 |

요청: "첨부 자료로 성과지표에 맞춰 실적보고서 써줘" → **모드 C**(자료 + 성과지표), 양식 없음 → 기본 지면, 쪽수 지정 없음 → 2쪽

## 눈여겨볼 판단
1. **지표가 목차를 정함**: 세부평가내용 ①체계 ②위험요인 발굴 ③안전문화 → 대제목 1·2·3, 같은 순서
2. **수치 충돌 처리**: 계획서의 중간 점검(돌발 고장 4건, 6월)보다 결과보고(3건, 9월)를 채택
3. **목표 대비**: 계획서의 목표(7건 이하)를 찾아 '초과 달성'으로 연결
4. **지적사항 대응**: 전년 지적 '관리자 점검 의존' → 2번 섹션에서 지적 → 조치 → 결과(협력사 신고 41%)로 대응
5. **지어내지 않음**: 자료에 상위 정책 언급이 없으므로 배경 박스를 '설비 현황 / 기존 방식 / 지표 착안점'으로 구성
6. **미완 자료 제외**: '드론 점검 ??(검토 중)'은 넣지 않음
7. **문제-성과 짝**: 문제 '돌발 고장 14건' ↔ 성과 '14건 → 3건'
