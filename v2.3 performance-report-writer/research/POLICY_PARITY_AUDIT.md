## 경량화를 위해 바뀐 실행 방식

| 변경 | 품질 규칙 변화 여부 |
|---|---|
| 01~09 순차 로딩을 조건부 6문서로 변경 | 정책 내용은 유지, 읽는 조건만 분리 |
| `facts.md`·`compare.md`·`direction.md`·`storyline.md`·`style.md`·`visuals.md`를 `work/ledger.md`로 통합 | 필드는 보존, 파일 수만 축소 |
| PDF 전체 쪽 연락판을 기본 생성하지 않음 | PDF 자체 시각 분석을 우선하고 필요 시 `--pdf-pages`; 그림 후보화 의무 유지 |
| 렌더 명령을 `render_report.py` 한 번으로 통합 | 기존 렌더러를 호출하며 결과 형식·점검 규칙 유지 |
| 배포 ZIP에서 README·연구·예시·개발 도구 제외 | 런타임 파일은 유지; 저장소에는 문서·연구 보존 |

## 의도적으로 보존하지 않은 v2.2의 문제

- `references/`의 개정 전 문장과 `SKILL.md` 보정표가 동시에 존재하는 충돌 구조
- 기본 양식과 모순되는 최상단 BEST PRACTICE 예시
- 그림 0~3개·그림부터 제거 등 v2.2 `SKILL.md`가 이미 폐기한 개정 전 규칙
- 모든 보고서 경로에서 단계 문서를 거의 전부 읽는 고정 라우팅
