# 원자료 그림과 이미지 삽입 자리

원자료 A의 사진·그래프·화면·도식을 적극 사용한다. 기준 양식은 6쪽에 그림 약 23개(첫 쪽 0개, 나머지 3~8개)였으나 현재 자료·쪽수에 맞춰 선별한다. B의 그림을 복사하거나 출처에 없는 사진·그래프를 만들지 않는다.

## 1. 전수 후보화

1. 텍스트 분석 후 `_images.md`와 모든 `images/_sheet_N.png` 연락판을 한 번씩 확인한다. 연락판은 전수 확인용이며 선택 원본만 크게 연다.
2. PDF는 Claude가 받은 문서의 페이지 시각요소를 우선 확인한다. 벡터 그래프 위치를 못 찾았을 때만 `read_inputs.py --pdf-pages`로 저해상도 페이지 연락판을 만들고, 필요한 영역만 `crop_pdf.py`로 자른다.
3. 각 그림을 `주장과의 직접 관련성 / 증거 가치 / 축소 가독성 / 조직 원자료 여부 / 중복 / 보안·개인정보`로 판정해 원장에 남긴다.
4. 조건을 통과한 그림은 관련 칸이 있는 한 배치를 시도한다. 뺀 그림은 조건 불충족·쪽당 상한·지면 등 사유를 기록한다.

우선순위는 성과 그래프·전후 화면 > 결과물·시스템 화면 > 실제 현장·수상·협업 사진 > 설명 도식·조직도다. 글자가 빽빽한 슬라이드 전체·표 그림·로고·아이콘·배경·클립아트·흐린 사진·동일 장면 반복·보안 정보가 보이는 그림은 제외한다.

## 2. 개수와 배치

- 목표는 쪽당 **2~4개**, 첫 쪽 **0~1개**, 최대 **5개**다. 실제 그림과 `[이미지 삽입]` 표시를 합쳐 세며 사진 띠는 1개로 센다. 자료와 자리가 있을 때의 목표일 뿐 억지로 채우지 않는다.
- 그림은 해당 문장·수치와 같은 칸, 바로 아래 또는 같은 열 하단에 둔다. 한 칸에 그림 1개가 기본이며 같은 그림은 한 번만 쓴다.
- 칸 아래는 높이 20~32mm, 칸 옆은 폭 25~35mm, 성과 행 끝 작은 사진은 폭 18~25mm, 카드 그림은 높이 22~30mm, 사진 띠는 높이 20~25mm를 시작값으로 한다.
- 원본 비율을 유지하고 의미 있는 부분을 자르지 않는다. 캡션은 무엇·시점·출처를 짧게 쓴다.
- 지면이 넘치면 `그림 높이 축소(최소 18mm) → C등급·중복 문장 제거 → 이미지 삽입 표시 제거 → B·C등급 섹션 그림 제거` 순이다. 핵심 근거 문장을 그림 때문에 빼지 않는다.

## 3. `[이미지 삽입]` 표시

원자료에 맞는 그림이 없지만 실제 사진·화면이 있으면 평가자가 더 빨리 이해할 자리에 담당자가 교체할 표시 상자를 둔다. 이미지를 만들거나 지어내는 것이 아니다.

우선순위:

1. 협약·발족·수상·표창·행사 → 행사 사진
2. 시스템·앱·플랫폼 구축·개선 → 화면 캡처
3. 시설·설비·현장 개선·장비 도입 → 현장 사진
4. 교육·체험·훈련 → 교육 현장 사진
5. 조직·추진체계 구축 → 조직도·구성도 원본
6. 모델·분석 결과 → 원본 결과 그래프

그림 객체에서 `src`를 빼고 `label`을 쓴다.

```json
{"img":{"label":"[이미지 삽입] 위원회 발족식 단체 사진","h_mm":24,"w_mm":34}}
```

- 라벨은 `[이미지 삽입]`으로 시작하고 필요한 장면을 15자 안팎으로 구체화한다.
- 칸 옆은 `"pos":"right","w_mm":28`, 칸 아래는 `w_mm` 30~40을 준다.
- 표시만 쪽당 0~2개이며 실제 그림과 합쳐 쪽당 5개 이내다. 실제 그림을 쓸 수 있는 자리에는 두지 않는다.
- 사용자가 표시 없이 작성하라고 하면 넣지 않는다.
- 코드 없는 지면안은 `[이미지 삽입 필요: 무엇 — 위치]`로 쓴다.

최종 답변에 `쪽 | 위치(섹션·칸) | 필요한 사진·화면` 목록을 넣고, Word에서는 회색 상자를 지우고 그 자리에 실제 그림을 넣는다고 안내한다.
