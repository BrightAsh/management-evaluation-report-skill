# 양식이 없을 때의 기본 지면

첨부 기준 양식에서 확인한 6쪽 구조만 기본값으로 쓴다. 원본의 내용·그림은 사용하지 않는다. A4 세로, 흑백·회색 계열의 고밀도 모듈형 지면이며 렌더러와 `assets/content_template.json`을 사용한다.

## 1. 쪽 틀

| 위치 | 짝수 쪽(왼쪽 면) | 홀수 쪽(오른쪽 면) |
|---|---|---|
| 머리말 | 왼쪽 장 번호 상자+장 제목, 오른쪽 끝까지 선(`chapter`) | 오른쪽 회색 띠 안 쪽 머리 제목(`running`) |
| 바닥글 | 왼쪽 쪽번호│기관명(`org`) | 오른쪽 슬로건│쪽번호(`slogan`) |
| 옆 탭 | 없음 | 오른쪽 가장자리 세로 글(`sidetab`) |

기관명·슬로건은 A에 있을 때만 넣고 로고 그림은 넣지 않는다.

## 2. 첫 쪽과 위계

첫 쪽은 위에서 아래로 정확히 다음 순서다.

1. `title`: `Ⅰ. 20XX년 평가내용별 추진실적 및 성과`
2. `ev`: 왼쪽 `평가내용 1`, 오른쪽 평가 항목 원문
3. `key`: 왼쪽 `핵심성과`, 오른쪽 핵심 메시지 1문장
4. 바로 `sec` 대제목 1 → `sub` 가. → 본문

최상단 BEST PRACTICE·대표 사례 요약·KPI·비전 상자는 만들지 않는다. 평가내용이 여럿이면 `ev + key → 관련 대제목`을 반복한다.

- 대제목: 진회색 번호 상자 + 굵은 주장형 제목 + 오른쪽 끝까지 밑줄
- 중제목: `가·나·다·라` 굵은 글. 대표 사례는 끝에 작은 진회색 `B.P` 태그만 붙인다.
- `B.P`는 문서 전체 2~3개 이내, 대제목마다 0~1개이며 흐름상 자연스러운 위치에 둔다.
- 기본 밀도: 6쪽에 대제목 약 4개, 대제목당 중제목 3~4개, 쪽당 중제목 2~3개. 대제목은 쪽 중간에서도 시작할 수 있다.

## 3. 본문 블록

기본 단위는 `grid`: 왼쪽 회색 라벨 칸 + 내용 열 1~5개다. 열 머리는 회색 띠, 칸 첫 줄은 실행 단위·시점, 칸 안 문장 앞에는 `[[성과]]`·`[[기능]]`·`[[내용]]` 키워드 상자를 한 칸에 1~2개 쓴다. 추진성과 행은 진한 라벨 + 연한 띠다. 대제목은 추진성과·향후계획·기대효과 중 자료로 확인되는 행으로 닫는다.

| 내용 성격 | 블록·행 흐름 |
|---|---|
| 전략·체계 | `grid`: 환경분석→시사점·비전→로드맵·목표→전략방향·전략과제 |
| 조직·역할 | `grid`: 역할→추진내용→추진성과 |
| 문제 해결 | `grid`: 현황 및 문제점→추진내용→추진성과 |
| 협력·생태계 | `kv + grid`: 추진배경→개요→참여자→실적→향후계획 |
| 단계 추진 | `flow`: 시기 태그 3개와 연결 기호→진한 결과 띠 |
| 과제 하나 | 3열 `grid`: 추진배경│추진내용│성과 |
| 전후 개선 | `grid`: 기존→개선→추진성과 |
| 목적·모델 | `kv` 안 작은 표·그래프·사진→`chev` 향후 단계 |
| 여러 현장 | `boxes`→카드→`strip` 사진 띠→`res` 기대효과 |
| 좌우 비교 | `cols`→`res` |

## 4. 기준 양식에서 확인한 배치 패턴

| 원본 위치 | 배치 |
|---|---|
| 1쪽 1-가 | 환경분석 5열→시사점·비전→로드맵·목표·전략방향·전략과제 3열 |
| 1쪽 아래 | 구획 배너→정부과제 선정·내용 표 |
| 2쪽 1-나 | 역할 3열→추진내용(칸 아래 그림 3개)→추진성과 |
| 2쪽 1-다 B.P | 3열 현황 및 문제점→추진내용→추진성과+각주 |
| 3쪽 1-라 | 추진배경→개요 그림→참여자 4열→칸별 사진→향후계획 |
| 3쪽 2-가 | 시기 태그 상자 3개 `+`→결과 띠 |
| 4쪽 2-나 B.P | 추진배경│추진내용(가운데 그래프)│성과 |
| 4쪽 2-다 | 이슈·개선 2열→추진성과 끝 작은 표창 사진 |
| 4쪽 2-라·5쪽 3-가 | 기존→개선(옆 앱 화면)→추진성과 |
| 5쪽 3-나 | 추진목적→작은 표·그래프·결과 사진→향후계획 3단계 |
| 5쪽 3-다·6쪽 4-다 | 큰 묶음 2개→카드 4개→사진 띠→기대효과 |
| 6쪽 4-가 | 추진배경 상자 3개→번호 카드 3개(카드마다 그림) |
| 6쪽 4-나 | 추진배경│3단 추진내용+옆 화면→추진성과 |

이 표를 쪽별 고정 템플릿으로 복제하지 말고, 현재 스토리라인과 같은 내용 성격의 패턴만 고른다.

## 5. 문체·색·밀도

- 개조식 명사형, 한 항목 1줄(최대 2줄), 제목은 `수단 + 으로 + 결과`.
- 본문은 명조, 제목·라벨·칸 머리는 고딕. 기준 시작값은 본문 12pt, 중제목 15pt, 대제목 17pt, 첫 쪽 제목 19pt, 각주 9~10pt다.
- 무채색만 쓰고 흰색·밝은 회색·진회색 농도로 위계를 만든다. 둥근 장식 카드와 큰 장식 여백은 만들지 않는다.
- 지정 쪽수를 맞추되 글자를 줄여 억지로 넣지 않는다. 한 카드·칸은 2~3항목, 한 항목은 최대 2줄이다.
- 근거가 충분하면 흰 공간이 거의 없는 지면을 만들고, 부족하면 저등급 내용을 늘리지 않는다.

그림의 선택·개수·자리 규칙은 `visuals.md`, 블록 필드는 `layout_render.md`를 따른다.
