# 양식이 있을 때

스토리라인을 먼저 확정한 뒤 B를 적용한다. B는 구조·말투·지면만 제공하며 다른 조직·연도의 사실·수치·그림은 절대 가져오지 않는다.

## 1. 양식 프로필

B의 모든 쪽을 먼저 훑고, 반복되는 유형별 대표 쪽을 이미지와 텍스트로 확인한다. 원장에는 다음만 기록한다.

- 쪽수·여백·단/열, 머리말·바닥글·쪽번호
- 제목 위계, 칸 이름과 순서, 표·카드·흐름도 구성
- 문장 종결, 글머리표, 제목 문법, 문장 길이, 숫자 표기
- 색·글꼴·크기·간격·선, 수치 강조, 자주 쓰는 라벨
- 그림의 위치·크기·캡션 방식

문장이 있으면 실제 문장 10개 이상에서 말투를 확인한다. 반복 페이지를 같은 깊이로 중복 분석하지 않는다.

## 2. 적용

1. 스토리라인 섹션을 B의 칸에 대응한다.
2. 일반 칸(배경·내용·성과)은 유지하되 안을 A/C 근거로 채운다.
3. 다른 조직 사업명인 제목은 C 또는 현재 축의 핵심어로 바꾼다.
4. 칸 순서가 문제→조치→성과 흐름을 끊으면 필수 칸은 유지하고 칸 안 근거 순서와 강조로 흐름을 살린다.
5. 기존 렌더 블록으로 표현하고, 불가능할 때만 HTML·Word 양쪽에 새 블록을 추가한다.

B에 최상단 BEST PRACTICE나 다른 고유 요소가 실제로 있으면 따른다. 없으면 새로 만들지 않는다. B의 빈칸을 채우려고 C등급 사실, 중복 사실, 근거 없는 기대효과를 넣지 않는다.

## 3. 문체

B의 종결·기호·숫자 표기를 우선한다. 기본값이 필요하면 개조식 명사형, 한 항목 1줄(최대 2줄), 핵심 수치만 굵게 쓴다. 주체가 중요할 때만 앞에 쓰고, 근거 없는 `혁신적·최고·획기적`은 쓰지 않는다.
