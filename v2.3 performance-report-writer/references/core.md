# 핵심 분석·스토리라인

## 1. 판별과 전체 읽기

첨부마다 `파일 | A/B/C/D | 근거`를 원장에 기록한다. 한 파일에 역할이 섞이면 쪽 범위를 나눈다. 작년 우리 보고서는 A+B, 다른 조직의 완성 보고서는 B, 평가 결과·지적사항은 C로 본다. D의 쪽수·글자 크기·필수 항목·금지 표현은 제약으로 옮긴다.

`read_inputs.py`의 `_inventory.md`와 추출 텍스트로 A를 처음부터 끝까지 읽는다. 같은 사업의 계획→중간→결과→평가 제출본을 묶는다. 앞부분·파일명·조직명만으로 방향을 정하지 않는다.

## 2. 사실과 선별

사실마다 ID, 사업, 무엇이 달라졌는지, 시점·주체, 기준→결과 값, 상태, 유형, 외부 인정, 파일·쪽/행 출처를 남긴다.

- 상태: 계획 / 진행 / 완료 / 목표·추정
- 유형: 투입 / 활동 / 산출 / **성과** / **파급**. 성과·파급을 우선하고 활동만 있는 사업은 비중을 낮춘다.
- 충돌: 결과보고 > 평가 제출본 > 중간보고 > 계획안, 같은 단계는 최신 자료. 다른 값과 판단 이유도 남긴다.
- 미완 표기, 실적기간 밖 값, 출처 없는 수치는 본문에서 제외하고 확인 사항에 남긴다.

사업을 `지표 적합성 / 성과 수준 / 차별성 / 인과 명확성 / 지속·확산`으로 각 0~3점 평가한다. 12점 이상 A(대표 사례), 7~11점 B(본문 사례), 6점 이하 C(한 줄 또는 제외)로 삼되, 성과지표가 요구한 지정 과제는 점수와 무관하게 넣는다. `최초·유일`은 원문 근거가 있을 때만 인정한다.

## 3. 비교 값과 지적사항

전년·도입 전후·목표 대비처럼 같은 지표의 두 값을 찾는다. 정의·단위·범위·집계기간이 같고 두 값에 모두 출처가 있으며 현재 주장을 직접 뒷받침할 때만 쓴다. `scripts/compare.py`로 계산하고 비율은 %p, 점수는 점 차이를 구분한다.

- 기준값이 작아 증감률이 과장되면 실수치나 배수로 표현한다.
- 같은 비교는 가장 적합한 한 곳에 쓴다. 주장 하나에 대표 비교 하나, 섹션당 1~3개를 우선한다.
- 불리한 값도 지적 대응과 관련되면 숨기지 않는다.
- 전년도 지적사항은 모두 검토하되 `지적 원문 → 올해 조치 → 결과`가 자료로 이어지는 것만 본문에 쓴다. 나머지는 미반영 사유를 남긴다.

## 4. 방향

C가 없으면 보고서 종류·실적기간·상위 방향을 확인하고 `왜 했나 / 어떻게 계획했나 / 무엇을 했나 / 무엇이 달라졌나 / 어떻게 이어가나`로 축을 찾는다. 성과 언어는 실제 업무에 맞춘다(효율·시간·비용, 안전·위험, 고객·만족, 생산·수익, 역량·참여, 기술·정확도, 상생·수혜 등). 자료에 없는 분야나 KPI를 끼워 넣지 않는다.

핵심 메시지는 `[누가] [무엇으로] [무엇을 바꿨다]` 한 문장이다. 이를 받치는 겹치지 않는 축 2~4개를 `수단 + 으로 + 결과`로 만든다. C가 있으면 `indicators.md`의 지표 구조가 우선한다.

## 5. 스토리라인

문장과 지면보다 먼저 원장의 쪽별 표를 완성한다.

1. 문서 전체는 핵심 메시지 → 축 → 근거, 각 섹션은 주장형 제목 → 사례 → 숫자 순이다.
2. 대·중제목만 이어 읽어도 핵심 메시지가 보여야 한다.
3. 문제에서 꺼낸 값은 가능한 한 같은 단위의 성과로 돌아온다. 대응 성과가 없으면 문제 표현을 바꾸고 수치를 만들지 않는다.
4. 같은 사실은 가장 적합한 한 곳에만 쓴다. 종합성과 요약은 예외다.
5. 대표 사례를 앞에 두고 다른 사례보다 1~1.5배 지면을 준다. C 배점이 있으면 배점 비율을 우선한다.
6. 모든 대제목은 3줄 이내 성과·기대효과·향후계획 중 자료로 확인되는 내용으로 끝낸다. 처음의 약속이 마지막에서 확인돼야 한다.

| 패턴 | 흐름 |
|---|---|
| 문제 해결 | 배경→문제(정량)→전환→추진→전후 성과→확산 |
| 체계 구축 | 필요성→조직·제도·절차→운영→성과→정착 |
| 단계 확장 | 과거 단계→올해 단계→다음 단계→누적 성과 |
| 지적 대응 | 지적 원문→원인→조치→결과→재발 방지 |
| 과제 묶음 | 방향→과제별 기존·개선→종합 효과 |
| 협업 확산 | 협업 구조→공동 추진→각 주체 성과→확산 |
| 약식 | 추진방향→추진내용→추진성과 |

## 6. 최종 검증

- 모든 수치·날짜·주장을 사실 ID와 원문 검색으로 대조한다.
- 계획/완료, 목표/실적·추정을 다시 확인한다.
- C의 필수 평가 항목과 D의 제약마다 대응 위치가 있거나 자료 부족이 명시돼야 한다.
- 제목 이어 읽기, 문제-성과 단위, 인과, 중복, 쪽별 대표 숫자를 확인한다.
- 약한 내용을 늘려 빈칸을 채우지 않는다. 넘치면 C등급·중복부터 뺀다.
